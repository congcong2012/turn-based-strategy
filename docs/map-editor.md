# 地图编辑器（`#/editor`）

> 给**自己**做地图并直接在单人练习里玩。入口：主页「地图编辑器」，或单人练习设置页的「打开地图编辑器」。

## 1. 怎么用（三步）

1. 从模板起步：打开编辑器就是一张 **24×24 两人图**（上下两条部署带、各自王城与兵营、中间交叉的村落）。
   想换规模就改「宽 / 高 / 玩家数」——改尺寸会**保留已画的内容**，超出范围的部分丢弃并提示。
2. 画笔刷：地形（平原 / 道路 / 森林 / 山地 / 河流）、据点（王城 / 兵营 / 村落，先选归属再往图上点）、
   部署区（选玩家后**拖出一个矩形**）、橡皮（擦据点）。
   校验面板实时显示问题：**红色必须改完才能保存**，黄色只是提醒。
3. 「用这张图开始单人练习」→ 会**自动保存**并跳到单人练习设置页（地图已预选），点「开始对局」即可。

## 2. 数据格式

编辑器产出的就是内核用的 `MapDef`（`src/game/data.ts`），**与内置地图完全同构**，
所以自制图可以直接替换官方图，反之亦然：

```jsonc
{
  "id": "user_xxx",          // 自制图固定以 user_ 开头（与内置 ancient_* 区分）
  "name": "我的渡口",
  "width": 24, "height": 24,
  "terrain": ["plain", "plain", "forest", ...],   // 长度 = width × height，按行优先
  "buildings": [
    { "id": "b1", "type": "hq",       "x": 12, "y": 2,  "owner": 0 },
    { "id": "b2", "type": "barracks", "x": 7,  "y": 2,  "owner": 0 },
    { "id": "b5", "type": "village",  "x": 12, "y": 12, "owner": null }  // null = 中立
  ],
  "deployZones": [ { "x0": 0, "y0": 0, "x1": 23, "y1": 3 } ]  // 一个矩形 = 一个玩家席位
}
```

几条约定（编辑器会自动维护，但手改 JSON 时要留意）：

- **据点所在格的地形必须是 `building`**：否则该格会按平原/森林算移动消耗与防御，**数值和看起来的不一样**。
  编辑器保存前会统一补上。
- **`deployZones.length` = 玩家数**（2–4），且顺序就是座位顺序（`0` 号先手）。
- **每个玩家有且只有一个 `hq`**（斩首胜负依赖它）；`owner` 是玩家序号（从 0 起）。
- 部署区是**矩形**，所以编辑器用"拖矩形"而不是"漆格子"——漆完再取包围盒会把没画的地方也圈进去。

## 3. 校验规则（`src/game/mapValidation.ts`）

| 级别 | 例子 |
| --- | --- |
| **错误**（拦保存） | 地形数组长度 ≠ 宽×高；未知地形 id；整图没有可通行格；部署区数量不在 2–4；部署区越界 / 没有可站立格；据点 id 重复 / 同格两个据点 / 坐标越界 / 类型未知 / 压在不可通行地形上；某玩家没有王城或有多个王城；据点归属序号越界 |
| **提示**（只提醒） | 某玩家没有兵营（整局造不了兵）；没有中立村落（没有可抢的收入点）；王城不在自己的部署区内；据点格地形没补成「据点」；部署区可站立格少于部署上限；名称过长 |

同一份校验也用在**读存档**时：任何一张不合法就**单独丢弃**，不影响其它地图。

## 4. 存储与分享

- 自制地图存在**浏览器本地**（localStorage 键 `ancient-tactics.maps`），不联网、不上传。
- **只用于单人练习**：联机时其他玩家手里没有这张图，房主选了它别人渲染不出来。
- 想让好友也玩到（或想让它变成人人可选）：
  **「导出 JSON 文件」→ 把文件放进 `src/data/maps/` → 在 `src/game/data.ts` 的 `BUILTIN_MAPS` 里登记一行**。
  它就成了内置地图：大厅选图、单人练习、联机对战都能用。
- 导入：把 JSON 粘进编辑器的「粘贴 JSON 导入」，或直接改文件。

> 导入时如果 id 还是 `ancient_*`（比如你导出的是内置图），编辑器会**自动换成新的 `user_` id**，
> 避免覆盖内置地图、也避免和别人的图撞 id。

## 5. 相关文件

| 文件 | 职责 |
| --- | --- |
| `src/ui/MapEditor.tsx` | 编辑器页面：笔刷、校验面板、存档列表、导入导出、试玩 |
| `src/ui/mapEditorCanvas.ts` | 画布绘制与"屏幕坐标 → 格子"命中测试（纯函数，可单测） |
| `src/game/mapValidation.ts` | 地图校验（错误 / 提示两档） |
| `src/game/mapTemplates.ts` | 模板地图工厂与改尺寸（保留交叠内容） |
| `src/app/mapStore.ts` | 本地持久化、规范化、导入导出、注册进运行时地图表 |
| `src/game/data.ts` | `BUILTIN_MAPS`（内置，仅大厅用）与 `DATA.maps`（运行时表，含自制图） |

## 6. 两个容易踩的坑（已修，改代码时别改回去）

1. **保存地图必须同时注册进 `DATA.maps`**。运行时的 `getMap` / 存档校验只看这张表；
   若只写 localStorage，会出现"设置页能选、一点就抛「未知地图」"（甚至整页白屏），
   或"单人局静默回退到内置图"。所以 `upsertUserMap` 内部就做了 `registerMap`。
2. **启动时必须先 `installUserMaps()` 再读存档**（`src/main.tsx` 的顺序）。
   自制地图只存在本地，晚一步装载，用自制图开的局就会因为"地图查不到"被判非法存档而清掉。
   `tests/e2e/editor.spec.ts` 的"刷新后仍能恢复"就是守这条的。
